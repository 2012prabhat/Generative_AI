# 📘 Python Assignment

This repository contains solutions for 4 different tasks implemented in Python.

## 📂 Project Structure

The project includes the following files:

* `app_basic.py` → Solution for Task 1
* `app_discount.py` → Solution for Task 2
* `app_product_form.py` → Solution for Task 3
* `app_dashboard.py` → Solution for Task 4

## 🚀 How to Run

1. Make sure Python is installed on your system.
2. Open terminal or command prompt.
3. Navigate to the project folder.
4. Run any file using:

```bash
streamlit run app_basic.py
```

## 📌 Requirements

* Python 3.x
* Streamlit ( install it from pip )
